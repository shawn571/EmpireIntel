# External reviews

Store review documents here UNEDITED with dated names, for example `2026-11-05_ChatGPT_Architecture_v1_Review.md`.
Outcomes go to `External_Review_Log.md` (created with the first review): one row per finding,
`ID | claim | evidence tier | verdict | technical justification | resulting action`.
Accepted items then go to Decisions.md, Risk_Register.md, Compatibility_Notes.md or TODO.md (Project_Bible.md section 2).
Remove names and account details before storing a review (public repository).
